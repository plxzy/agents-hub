What one request costs

The orange dots are main-model calls you pay for on top of the agent's own work.

pi-subagents, from the CLI

  1. Main model reads your message, calls Agent
  2. helper runs: 4 tool calls, 7.6k tokens, 14 s
  3. Main model fetches the result
  4. Main model repeats the answer to you
≈28k main-model tokens around a 7.6k run. In the TUI with direct mentions: no main-model calls.

Pi Fabric, worker + reviewer

  1. Main model searches Fabric's capabilities
  2. Main model writes one program: run worker, feed its answer to reviewer
  3. worker: 5 turns, 6 tool calls, $0.0016
  4. reviewer: checks the sources, finds 1 issue
  5. Main model summarises
≈32k main-model tokens, 62 s total. Children ran at medium thinking although you set low.

Words that keep coming up

Harness
The loop that runs one agent: send prompt, run tools, repeat. Pi is yours.
Orchestration
Code or a model deciding which agents run, in what order, and who checks whom.
Durable
A run that keeps its place after a crash or restart and continues instead of starting over.
Session vs run
A session is one conversation. A run is one bounded job inside it, with a start and an end.
Main model / routing cost
When you ask one model to hand work to another agent, that hand-off is paid model work too.
Code mode
Fabric's default: the model gets one tool and writes a small program instead of calling tools one by one.
Memory candidate
A note an agent proposes. It only reaches future runs after you accept it.
Receipt / trace
A record of what a run did: model, tools, tokens, cost. Langfuse collects these as traces.
PCC
Apple Private Cloud Compute: Apple's bigger model on Apple servers, reached through fm.
